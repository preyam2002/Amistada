# Amistada

## Overview
Web app with 3D visualization and Supabase backend.

## Commands
```bash
npm run dev       # Next.js dev
npm run build     # Production build
```

## Tech
- Next.js 16, React 19, TypeScript
- Three.js / React-Three-Fiber (3D)
- Supabase (DB + Auth)
- OpenAI SDK
- Framer Motion, Tailwind CSS
